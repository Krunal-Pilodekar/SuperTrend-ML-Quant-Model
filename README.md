# SuperTrend-ML-Quant-Model
MT5 multi-timeframe trend-following bot using SuperTrend, DEMA, and ADX. Includes live trading, multi-asset backtesting, walk-forward optimization, and optional ML trade filters for XAUUSD, EURUSD, GBPUSD, and USDJPY. Research-focused project with out-of-sample validation and transparent performance reporting.
